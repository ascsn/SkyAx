Dynamic damping of constraint according to actual density \textquotesingle{}rho\textquotesingle{}. The nuclear surface line is defined with respect to a certain critical density value. The distance to the surface line is evaluated, and the constraint field is attenuated with a Saxon-\/\+Woods profile using this distance.  Three ways of defining the distance of the surface are tested\+: 


\begin{DoxyItemize}
\item damp\+\_\+constraint\+: distance of an outer point (rho$<$rho\+\_\+critical) is the minimal distance to an inner point (rho$>$rho\+\_\+critical) and vice versa.
\item delrmn\+: the surface line is evaluated as r(z) using linear interpolation of density. Then the distance is computed as the shortest distance to this surface line.
\item damint\+: similar as {\ttfamily delrmn}, but using direct linear interpolation between the gid points. The first way in \textquotesingle{}damp\+\_\+constraint\textquotesingle{} is actually used and stored in the array for constraint. The other schemes are evaluated and printed for comparison.
\end{DoxyItemize}

N\+O\+TE\+: This is a routine in development and requires further investigations before it can be used in production runs. Open problems are, e.\+g., lack of truly variational formulatio (the actual \textquotesingle{}rho\textquotesingle{} is used) and discontinuities due to box interpolation )in \textquotesingle{}damp\+\_\+constraint\textquotesingle{}) and, less so, to linear interpolation.
