\subsubsection{Detailed Description}
This module contains routines to compute Hamiltonian matrices and to diagonalize them. The matrices are always assumed to be in blocks for groups with equal m quantum number.

Computes one line of a Hamiltonian matrix submatrix with equal quantum number m. 

The subroutine takes the Hamiltonian applied on a wave function with index {\ttfamily jst} and calculates the overlap with wave functions with the same quantum number m. If the parity in z-\/direction is different, the overlap is set to 0.
