Routine to solve the Lipkin-\/\+Nogami or B\+CS equations. . 


\begin{DoxyItemize}
\item gap equation\+: \[ 0 = \texttt{f1} = \texttt{delta}-\texttt{gpair}\cdot \sum(uv) \]
\item particle number\+: \[ 0 = \texttt{f2} = \sum(2v^2)-n \]
\item particle number fluctuation\+: \[ 0 = \texttt{f3} = \texttt{xlam2}-\texttt{gpair}/4 \cdot (\sum(u^3\cdot v)\sum(v^3* \cdot u)-\sum(u^4*\cdot v^4))/ ((\sum(u^2\cdot v^2))^2 - \sum(u^4 \cdot v^4)) \] Particle number fluctiation is ommited for B\+CS. The 3 equations are solved by Newton\textquotesingle{}s method. The matrix of derivatives is computed by finite differences.
\end{DoxyItemize}

Determines the fermi-\/energy {\ttfamily eferm} and the gap {\ttfamily delta} such that the \char`\"{}gap-\/equation\char`\"{} and the \char`\"{}particle number condition\char`\"{} are fulfilled simultanously. this is achieved by iteration with a gradient scheme (Newton\textquotesingle{}s tangential formula) where the gradient is evaluated by finite differences.  There are two schemes possible\+:
\begin{DoxyEnumerate}
\item The \char`\"{}constant force\char`\"{} approach, where the pairing force is given in \textquotesingle{}gp\textquotesingle{}.
\item The \char`\"{}constant gap\char`\"{} approach, where the gap is kept fixed and is given in {\ttfamily delta}.
\end{DoxyEnumerate}There is only {\ttfamily eferm} to be determined in the \char`\"{}constant gap\char`\"{} approach. The gap-\/equation is used at the end to determine an according force {\ttfamily gp}.
