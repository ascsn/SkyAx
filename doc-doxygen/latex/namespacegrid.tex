\subsubsection{Detailed Description}
This module contains the grid variables as well as the matrices and routines for computing derivatives and integrals. 

Derivatives can be calculated either using a standart n-\/point formula or the Fourier definition. In both cases matrices are constructed and functions have to be multiplied with those to obtain the derivatives. Special attention has to be given to symmetries. The symmetry in z-\/direction is controlled with the variable {\ttfamily sym} (or {\ttfamily isym}). Also the z-\/parity and m-\/component is taken into account.
