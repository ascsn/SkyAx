\subsubsection{Detailed Description}
This module contains the variables for the force definitions, termination criteria, parameters for iterations and dynamic variables for pairing. The routine {\ttfamily read\+\_\+force} reads forces from the input file or from forces.\+data.

The purpose of the subroutine is to read the force and pairing definitions. The N\+A\+M\+E\+L\+I\+ST {\ttfamily force} contains all the defining values for a Skyrme force (but now as individual variables, not in a derived type) plus a selection of pairing type and strengths (see input description). In addition there is a logical variable {\ttfamily turnoff\+\_\+zpe} which allows turning off the center-\/of-\/mass correction. 

Some quantities are first set large to see whether required input is missing. Then a predefined Skyrme force with the given name is sought; if it is found, it is simply copied into {\ttfamily f}. If no force of this name is found, a new one is composed from the numbers given in the input.

If the input varable {\ttfamily turnoff\+\_\+zpe} is true, the indicator {\ttfamily  f\%zpe } is set to 1, which implies not doing anything about the center-\/of-\/mass correction.

Now the \char`\"{}b\char`\"{} coefficients are calculated straightforwardly.

The variable {\ttfamily pairing} from the namelist then determines the pairing. If it is set to {\ttfamily \textquotesingle{}N\+O\+NE\textquotesingle{}}, no pairing is included. Otherwise the strength parameters are taken from the input or from the predefined force. If this process does not find a reasonable pairing combination, stop with an error message.
