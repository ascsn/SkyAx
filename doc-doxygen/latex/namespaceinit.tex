This subroutine initialises the damping matrices for the meson damping. 

The meson damping is given by\+: \[ d=\frac{1}{\texttt{dams}^2}\frac{1}{1-\Delta_r/\texttt{dams}^2} \frac{1}{1-\Delta_z/\texttt{dams}^2} \] where {\ttfamily dams} is a numerical damping mass and $\Delta_{r/z}$ is the delta operator in $r/z$ direction in axial symmetry.
