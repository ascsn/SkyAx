Detailed Description

This module contains routines to initialize output files, several parameters and variables, and wave functions.

Function/Subroutine Documentation

subroutine init::comp_block ( )

Computes the blocked state after some pre-iterations. Blocked is a state with kblock, mblock and isoblock as given in m_levels.f90. The routine finds out what number this state has in the normal ordering sequence of the code.

subroutine init::ssetup ( )

Initialises the psi with harmonic oscillator wave functions.

The routine is run twice. Once to determine the number of states and the second time to initialize wave functions and levels. After the first run the arrays are allocated with the exact number of states.
