subroutine pairin::respax ( integer, intent(in)  iter)

Calculates the contribution from the Skyrme residual interaction to lambda_2 in Lipkin-Nogami Pairing.

Computes the response-densities to the particle number operator using pairing weights from weight. The response Hamiltonian is constructed from the Skyrme-Energy-functional, for the details see [3] [4]. The Lipkin-Nogami does only proton-proton pairing and neutron-neutron pairing. Thus only the Z^2 and N^2 response is required. The procedure is extensively commented for the first term xpotp and xpotn. The other terms run analogously. Results are returned via

  • rspln = response energy to be used in Lipk.Nogami.
  • suv2r = , to be used in Lipkin-Nogami.
Parameters
[in]iterINTEGER, takes the current iteration number.
