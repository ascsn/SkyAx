Detailed Description

This module contains routines to compute Hamiltonian matrices and to diagonalize them. The matrices are always assumed to be in blocks for groups with equal m quantum number.

Computes one line of a Hamiltonian matrix submatrix with equal quantum number m.

The subroutine takes the Hamiltonian applied on a wave function with index jst and calculates the overlap with wave functions with the same quantum number m. If the parity in z-direction is different, the overlap is set to 0.

Parameters
[out]hmatrREAL(8), array, returns the Hamiltonian matrix.
[in]psiREAL(8), array, takes wave functions in current m-block.
[in]hpsiREAL(8), array, takes Hamiltonian applied to the wave function with index jst.
[in]nloINTEGER, array, takes index of first wave function in the m-block.
[in]jstINTEGER, takes index of wave function for which overlaps are calculated.
[in]ndimactINTEGER, takes size of current m-block.
