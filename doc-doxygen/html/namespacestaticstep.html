subroutine, public staticstep::sstep ( integer, intent(in)  iter)

Subroutine to propagate one gradient step.

First opens protocoll files and sets several variables. The main step is performed for blocks of same quantum number m separately. The Hamiltonian is applied to the wave function and the Hamiltonian matrix is constructed. All variances are accumulated. After damping the iteration step is performed. One extra subiteration can be performed. Then the wave functions are diagonalized and orthonormalized. The new densities are constructed (only rho for constraint iterations). In the next optional step, the constraints are applied and all densities are accumulated. Orthonormalization is performed again. Now the pairing weights and occupations are updated, optionally fields are printed and finally the new mean fields are evaluated.

Parameters
[in]iterINTEGER, takes the current iteration number.

Calculation of Q-corrective step and update of Lagrange parameter qlambda.

Various strategies to deduce 'qcorr' and 'qlambda' can be chosen:

  • ifqq = 0: difference of damped Q, local estimate of Delta Q
  • ifqq = 1: difference of damped Q, exact variances of damped Q
  • ifqq = 2: from raw Q and local estimate of raw Delta Q
  • ifqq = -1: augmented Lagrangian, requires proper setting of 'caugmlagr', still in testing stage. The routine updates the corrective array "wrk4". Note: option 'ifqq=1' requires smaller 'c0', typically around 0.2-0.3.
Parameters
[in]qfacREAL(8), array, takes the actual damped constraint.
[in]qcfacREAL(8), array, takes the actual raw constraint.
[in,out]qlambREAL(8), takes and returns the actual Lagrange parameter.
[in,out]qlambiREAL(8), takes and returns the intrinsic Lagrange parameter (augmented Lagrangian).
[in]qsollREAL(8), takes the wanted value of deformation.
[in]qqREAL(8), takes the variance of Q operator.
[in]qhREAL(8), takes the variance <Qh>.
[in,out]corrfieldREAL(8), array, takes and returns the w.f. correction.
[in]iterINTEGER, takes the current iteration number.
