Detailed Description

This module contains the grid variables as well as the matrices and routines for computing derivatives and integrals.

Derivatives can be calculated either using a standart n-point formula or the Fourier definition. In both cases matrices are constructed and functions have to be multiplied with those to obtain the derivatives. Special attention has to be given to symmetries. The symmetry in z-direction is controlled with the variable sym (or isym). Also the z-parity and m-component is taken into account.

subroutine grid::init_grid ( )

Initialization of the grid operations routines.

This routine determines the band widths for derivatives and calls the appropriate routines for initializations for the derivative matrices.

  • For idrtyp = 0: Fourier derivatives.
  • For idrtyp = 1: 9-point in r-direction, Fourier in z-direction.
  • For idrtyp = 2: Fourier in r-direction, 9-point in z-direction.
  • For idrtyp = 3: 9-point derivatives.
