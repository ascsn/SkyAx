Detailed Description

This module contains the routines to compute the mean-field Hamiltonian, applying it to a wave function, the Gram-Schmidt orthonormalization and other helper functions for the damped gradient step.

subroutine steputil::mfhmlt ( integer, intent(in)  iter)

Compute the mean field hamiltonian.

First the routine computes the mean-field potential, the inverse effective mass, the spin-orbit potential, and then the Coulomb potential. An octupule kick can be added to explore asymmetric shapes or an isovector dipole potential. The derivatives of the inverse mass are determined and finally prints and test plots are generated.

Parameters
[in]iterINTEGER, takes the iteration number.

subroutine to orthonormalize the set of states psiw new states are replaced in psiw.

If sym= 1.0 then npar (taken from fields npar(ist)) is a good quantum number and only those states having the same z-parity need be orthogonalized. If sym is 0.0 all states need be orthogonalized. The routine runs over one 'm'-block of the states. The wave functions are contained in psiw running from n = 1 through nhi. The corresponding global quantum number is computed with istadd as base point: ist = istadd + n . The norm of each component separately is returned on cmpn ; this serves as a diagnostic tool. * The orthonormalization should be done in order of increasing energy. The s.p. energies on spenrg are first sorted in energy order. This is done on a workspace eord. The ordering is stored in the pointer isort. eord and spenrg.

Parameters
[in,out]psiwREAL(8), array, takes the input wave functions.
[in]istaddINTEGER, takes the base point of the wave functions.
[in]nhiINTEGER, takes the number of the wave functions to be orthonormalized.
