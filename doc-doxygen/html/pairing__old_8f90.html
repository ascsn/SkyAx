Calculates the strength of the monopole pairing interaction using the average gap method. the average gap model is based on moller and nix, nucl. phys.a536 (1992)

  1. the average pair density is computed using the semi-classical approximation for the harmonic oscillator model modified by the isospin-dependent factor derived based on the wigner-kirkwood expansion for the woods-saxon potential (+ spin-orbit + coulomb).

    Parameters
    [in]ibcsINTEGER, switch for pairing mode. 1 for BCS or Lipkin-Nogami for all other values.
    [in]izINTEGER, takes the proton number.
    [in]inINTEGER, takes the neutron number
    [in]iprotINTEGER, switch for Neutrons (0) or protons (1).
    [in]rhoscREAL(8), takes semiclassical level density at Fermi surface, determined by function 'semrho' or by simple estimate if 'rhosc=0D0' is given.
    [in]n1INTEGER, takes number of first HF level used in the BCS (LN) calculations. (Preferably n1 = 1)
    [in]n2INTEGER, takes number of last HF level used in the BCS (LN) calculations. (Preferably n2 = npart, i.e., iz or in)
    [in]xmeffREAL(8), takes effective mass (=1 in the Wood-Saxon model).
    [in]a0REAL(8), takes surface parameter in a Saxon Woods shape, is 0.58 * surface width from formfactor

Determines the fermi-energy eferm and the gap delta such that the "gap-equation" and the "particle number condition" are fulfilled simultanously. this is achieved by iteration with a gradient scheme (Newton's tangential formula) where the gradient is evaluated by finite differences. There are two schemes possible:

  1. The "constant force" approach, where the pairing force is given in 'gp'.
  2. The "constant gap" approach, where the gap is kept fixed and is given in delta.

There is only eferm to be determined in the "constant gap" approach. The gap-equation is used at the end to determine an according force gp.

Parameters
[in]eREAL(8), array, takes single particle energies.
[in,out]gwREAL(8), array, takes occupation probabilities, input is used as initial guess for the iteration. Returns the resulting occupation probabilities.
[in]phREAL(8), array, takes the multiplicities of the single particle levels.
[in]nzINTEGER, takes the desired particle number.
[in]nmaxINTEGER, takes maximum number of single particle states (needs to be smaller than the parameter 'npsid' and smaller than 46, for dimensioning reasons).
[in,out]gpREAL(8), takes size of pairing-force, is input in case of "constant force" approach, output in case of "constat gap".
[in,out]efermREAL(8), returns Fermi energy, input is used as initial guess; if eferm=0.0 is input then a suitable initial guess is computed from input gw.
[in,out]deltaREAL(8), takes pairing gap; is input in case of "constant gap" approach, output in case of "constant force".
[in,out]partnmREAL(8), returns the particle number, from summing gw with degeneracy ph.
[in]iterREAL(8), takes number of pairing iterations, abs(iter) is the number of iterations.
[in]ipairINTEGER, takes pairing type (ipair=1: "constant force" approach, using pairing force 'gp'; ipair=0: "constant gap" approach, using given gap delta; ipair=4: thermal occupation with temperature given by delta.
[in]epsINTEGER, takes end condition for pairing iteration; iteration terminates if error in particle number is smaller than eps and if eferm and/or delta are smaller than eps.
[in]iabINTEGER, takes print level; significant values are -2, -1, 0 and 1; larger value prints more.
