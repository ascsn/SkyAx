Explanation of the extension of SkyAx to odd nuclei:
====================================================

There are three major steps:

  I. Extending the book-keeping to K<0 states:
     -----------------------------------------
     Even-even nuclei obey Cramer's degeneracy which 
     associates to each  s.p. state with K>0 (where K is
     the total spin z-component) an equivalent state with 
     K<0, called henceforth the pairing-conjugate state. 
     Thus the code for even-even nuclei handles only K>0 
     states.
     To allow for broken time parity, the quantum numbers
     are extended to cover now also the range K<0. 
     Those modifications in book-keeping cover the points
     1-5 and 24-27.

 II. Handle terms with time-odd densities:
     -------------------------------------
     Broken time parity activates the terms with time-odd
     densities in the functional (see the paper 'EPJA...'
     and for more technical detailes the apoendices in 
     'diplomarbeitt...', both in the subdirectory 'doc'). 
     These new terms must be implemented in the code. 
     This is done in the points 7-9,11,and 13-22.

III. Implement blocking for the odd nucleon:
     =======================================
     The odd nucleon and its pairing-conjgate state does 
     not take part in pairing. This is realized by what is
     called blocking of these tow states. Blokcking and
     its book-keeping is the most involved piece in coding
     and will require careful testing. A subtle case is
     the s.p. energy entering the pairing scheme. The
     pairing-conjugate state are note degenerated anymore.
     The average of the two s.p. energies si used. The 
     necessary modifications concern points 6, 12, 23, 24,
     and 27-30.



The extension introduces at the moment two new input parameters:
                                           ---------------------

isTsym =      level of treating time-odd terms
               0 --> use Cramer's degeneracy (standard for 
                     even-even nuclei)
               1 --> angular momentum K>0,K<0 separately, 
                     but no time-odd terms
               2 --> minimal Galilean invariant terms
               3 --> volume spin terms in Skyrme functional
               4 --> volume+surface spin terms in Skyrme 
                     functional (producing sometimes instabilities)
              For Fayans functionals use isTsym=2, 
              for Skyrme functionals isTsym=3 or 4.

istblo(1:2) = explicit choice of number of blocked state.
              This is a preliminary strategy for the testing phase,
              technically simply, inconvenient to use.
              It requires a two-pass computation. One does a first 
              run with 'istblo=0', i.e. without blocking. Then one
              looks through the s.p. states near the end of 
              'out_detail.*' and picks the state of interest. The
              number of the state in the sequence is entered via
              'istblo', for a proton state in 'istblo(1)' and for
              a neutron state in 'istblo(2)'. For odd-odd nuclei,
              one has to specify both entries.
              


There remain a couple of things yet to be done:
                                ---------------

* Testing is the priority task. First, we should make sure that
  the code still runs correctly for even-even nuclei. Then we
  should proceed to spherical odd-even and even-odd nuclei. 
  Benchmark results can be produced with the old Fortran77 code.

* Implement more automatic choice of blocked states. e.g. scanning
  all state near the Fermi energy with given K.

* Check and complete 'doxygen' entries, if we want to continue
  with documentation in 'doxygen'.
